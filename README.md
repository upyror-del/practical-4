# my_project

Навчальний проєкт для практичної роботи №4
«Управління процесом розробки програмного забезпечення (GitLab і GitHub)».

## Опис

Проєкт демонструє базовий робочий процес із Git:

- ініціалізація репозиторію та коміти;
- синхронізація з віддаленим репозиторієм (GitHub / GitLab);
- робота з гілками та злиття;
- вирішення конфліктів;
- відкат небажаних змін.
